# Outcast Acres Farm

Brand website for Outcast Acres Farm, a licensed New York adult-use cannabis
cultivator, processor, and distributor in Granville, New York. Be Different.

Static single-page site, no build step. Served by GitHub Pages from the main
branch root.

## Preview locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

See CLAUDE.md for the design system, compliance rules, and pending content
slots (farm video and photo grid).
